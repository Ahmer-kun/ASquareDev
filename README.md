# A² Dev Portfolio

Personal portfolio of Muhammad Ahmer (A² Dev), a MERN Stack and Web3 developer. The site features project showcases, technical writing, and development services.

Live: [asquardev.vercel.app](https://asquardev.vercel.app/)

## Built With

- React 19 with TypeScript
- Tailwind CSS
- React Router DOM
- EmailJS
- Vite

## Features

- Responsive design for all devices
- Dark theme with glass morphism effects
- Project gallery with live demo links
- Technical blog section
- Contact form with EmailJS integration
- Dynamic page titles for SEO
- Smooth scroll animations
- Live status display with UTC+5 local time
